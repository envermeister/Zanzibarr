## Zanzibarr v2.0 — search smarter, keep watching

Stream anything from Usenet. Own nothing. Wait for nothing. Zanzibarr plays NZB content **without downloading it** — instant start, frame-accurate seek, and only the segments you actually watch leave your provider.

v2.0 is a major search, discovery and continuous-playback update: multiple providers and indexers, Easynews web search, health pre-checks, saved searches, an episode queue, OpenSubtitles, remembered audio languages, runtime HDR10+ detection and Arabic subtitle fallback.

### Native Samsung Tizen and LG webOS TV — added 2026-11-23

The release now also contains three native TV preview packages from the v2.1 TV development line. The original v2.0 desktop/mobile assets and the v2.0 tag are unchanged.

- **Native playback with the same lazy engine.** Tizen and webOS use their platform `video_player` implementations while the Rust NZB/NNTP/yEnc/RAR/7z/PAR2 engine continues to serve only watched ranges through the local Range server. Search, health badges, episode queue, Up next, watch history and D-pad controls are shared.
- **Separate Samsung toolchains.** The Tizen 6.0 package uses GCC 9.2; the 2026 package uses the public Tizen 10 rootstrap and GCC 14.2. Both engines have no dynamic `libstdc++` dependency. webOS carries the exact LG NDK C++ runtime beside the engine and resolves it through `$ORIGIN`.
- **Native subtitles and audio.** OpenSubtitles SRT/WebVTT can be rendered by Flutter. Tizen supports audio-track selection, saved language preference and per-stream volume; webOS uses the default audio track and TV system volume.
- **Preview limitations.** These packages do not use media_kit/libmpv and do not claim the custom-libmpv Dolby Vision, TrueHD/DTS-HD or Smart Canvas capabilities from other platforms. Codec and HDR behavior depends on the TV media subsystem. Physical Samsung/LG installation, playback and remote-control validation is still pending; the TPKs use test signing and the webOS IPK is a test-development package, not production/store credentials.

### Search every source, not just one

- **Multiple indexer accounts, searched in parallel.** Enable any combination of Newznab-compatible profiles and merge their results into one list. **Prowlarr** and **NZBHydra2** work through their Newznab-compatible API endpoints — no separate integration or extra plugin required. Existing single-indexer settings migrate automatically.
- **Easynews web search joins automatically.** When your active NNTP provider is Easynews, the same account also searches the Easynews web API. Indexer and Easynews results arrive together, with an Easynews source chip where relevant.
- **Cross-source deduplication.** Matching releases collapse into one result instead of filling the page with copies; indexer priority follows your profile order.
- **Recent and saved searches.** Repeat a query from the recent chips, bookmark frequent searches, or clear the recent list. The controls are keyboard and D-pad accessible.
- **NZB health before playback.** Search results can show **Good / Repairable / Risky / Incomplete** badges. The engine combines NZB structure and PAR2 recovery capacity with a capped, time-boxed sample of NNTP `STAT` responses — article bodies are not downloaded for this check. The small NZB fetched for the check is reused when you press play.

### Season packs that keep playing

- **Play queue and automatic next episode.** Multi-entry NZBs continue in natural episode order. At EOF, a ten-second **Up next** card offers Play now, Finish episode and Clear queue; Back/Esc cancels the transition.
- **Watched-episode awareness.** Finished entries are marked in the picker, which focuses the first unwatched episode so continuing a season takes one selection.
- **Streaming stays lazy.** Building the queue performs no extra article fetches; the next episode starts streaming only when its turn arrives.

### Subtitles and audio that follow you

- **OpenSubtitles in the player.** Search by release name and moviehash, compare language/download-count/hash-match badges, pick your preferred languages and apply a subtitle without leaving playback. Your language and downloaded-file association carry into subsequent episodes. Configure your own OpenSubtitles consumer API key in Settings; free-tier downloads also require an account login.
- **Arabic subtitle fallback.** Bundled Noto Arabic fonts let libass fall back per glyph instead of rendering Arabic text as empty squares, without changing the selected primary font.
- **Remembered audio language.** Pick an audio track once and subsequent episodes prefer the same language when a matching track exists. Region-prefixed language codes are handled; Auto/No clears the preference.
- **Local-player subtitle note.** External OpenSubtitles files are applied to the local mpv player; they are not sent to Chromecast or AirPlay receivers.

### Accounts, HDR and platform polish

- **Multiple NNTP accounts.** Save named provider profiles and switch the streaming account from Settings. Saving a profile makes it active; legacy single-account credentials migrate without data loss. Parallel pooling across several NNTP accounts is not implied — one active account serves the stream.
- **Runtime HDR10+ confirmation.** For HEVC in start-code containers such as Matroska, Zanzibarr passively detects ST 2094-40 dynamic metadata in bytes already being served and adds an HDR10+ badge. This causes no additional media fetches. MP4 remains covered by release-name badges because its length-prefixed samples do not expose the same start codes.
- **Notarized macOS distribution.** The Apple Silicon app is signed inside-out with Developer ID and hardened runtime, notarized by Apple and stapled for offline Gatekeeper validation — no right-click workaround needed.
- **Preference reliability.** Canvas and periodic-info preference rebuilds now preserve subtitle-language, external-subtitle and audio-language choices instead of silently dropping them.

### Getting started

1. Install the build for your platform.
2. In Settings, save one or more NNTP provider profiles; the saved profile becomes the streaming account.
3. Add Newznab, Prowlarr or NZBHydra2 profiles if you want built-in search. Easynews web search needs no separate configuration when Easynews is the active provider.
4. Optionally add an OpenSubtitles consumer API key and account for in-player subtitle search/downloads.
5. Open an NZB or tap a search result — and let the next episode follow automatically.
